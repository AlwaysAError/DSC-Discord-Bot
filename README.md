# DSC-player-data-discord-bot
This code interrogates the DSC API into a Discord bot allowing user's to search for the name's of player's in game and get their ingame stats.
# SetUp
1. Drag and drop all file's to the file path: C:\Users\YOUR SYSTEM NAME HERE
2. Rename the file "FIXME.env" to ".env" removing the "FIXME" part of the file name.
3. Open the file ".env" and replace "BOT_TOKEN_HERE" with your bots Discord token and replace "CLIENT_ID_HERE" with your bots client ID.
4. Run the command
"npm init -y
npm install discord.js dotenv" in CMD.
5. Run the command "node register-commands.js" in CMD.
6. Last step to start all the code is to run the command "npm start" in CMD.
